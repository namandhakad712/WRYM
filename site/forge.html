Community Pipeline · Zero Backend

This page ships the exact engine, exhaustive BFS validator and seven-dimension difficulty index that certify the official ladder — compiled from the same source code CI runs. Paint a level, press Certify, and watch the search prove it solvable (or not). Then playtest it with the arrow keys, and submit it to the arena as a GitHub pull request. Merged levels appear on the public ladder with their certificate.

Everything runs locally in your tab — no server, no account needed beyond GitHub. The submission link opens GitHub's "new file" editor with your level pre-filled; committing it proposes a branch and opens the PR for you.

How a submitted level becomes arena canon — the full review framework

      
    
        
  1. You certify here. The BFS validator in this page is the same
        src/lib/wyrm codebase CI uses — if it passes here, it
        passes there. Solvability, optimal par, state count and the
        seven-dimension difficulty index are measured, not guessed.
    2. 
        
  2. You submit. The button opens GitHub's new-file editor at
        community-levels/<slug>.json with your level, certificate
        and contributor card pre-filled. Propose the change and GitHub
        opens a pull request for you — no tooling, no clone.
    3. 
        
  3. wyrm-bot judges the machine half. Within a minute of the PR
        opening, the bot re-certifies every changed level, re-validates the
        whole community ladder, posts a structured review card (par,
        difficulty, tier, states, mechanics on the optimal line — plus exact
        failures with fix hints), and labels the PR:
        bot:validated+
        bot:awaiting-review or
        bot:needs-revision — a failed
        submission is returned to you with everything needed to fix it.
    4. 
        
  4. A maintainer judges the human half. Design, fun, originality —
        the things no bot can measure. They either comment
        /wyrm approve (auto-merge engages) or
        /wyrm request-changes <reason> to return it with notes.
        Push a fix and the cycle restarts automatically.
    5. 
        
  5. Merge → live. wyrm-bot celebrates on the PR, the export
        pipeline picks the level up, the Pages site re-renders, and your level
        appears on the public ladder with runs, replays, its difficulty
        profile and your name on the certificate — every future
        benchmark run plays it.
    6. 
      

      
Track every submission in flight on the
      community board — live PRs, bot verdicts,
      maintainer decisions and merged levels with their contributors.
