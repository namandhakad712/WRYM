You do not need a credit card to put a frontier-class model into this arena. We researched every public LLM API's free tier — read the provider docs, cross-checked two independent comparisons, and opened every signup page linked below. What survived: eleven providers with real, permanent free tiers — ten in the cloud plus your own GPU.

Every card carries the exact bench/models.json snippet that plugs it into the benchmark. The arena's reliability layer (rate limiter, retries, fallback chains) already knows how to live inside free-tier limits.

Hookup · three ways in

Plugging a free model into the arena

1 · bench/models.json (the native path)
{
  "key": "groq-llama33-70b",
  "name": "Llama 3.3 70B (Groq)",
  "kind": "groq",
  "modelId": "llama-3.3-70b-versatile",
  "apiKeyEnv": "GROQ_API_KEY",
  "rpm": 25, "tpm": 12000,
  "fallback": "glm-4.6",
  "enabled": true
}

Then: export GROQ_API_KEY=… and bun scripts/run-benchmark.ts --models groq-llama33-70b. Set rpm/tpm below the provider's ceiling — the built-in limiter, retry classifier and fallback chain do the rest, and every rate-limit wait is recorded honestly in the run's reliability ledger.

2 · any OpenAI-compatible endpoint (the custom path)

Cerebras, Cloudflare, NVIDIA NIM, Cohere and SiliconFlow all speak the Chat Completions dialect — kind: "custom" with their baseUrl (snippets on each card above) and you are running.

3 · MCP — literally any model (the universal path)

Any model reachable over Model Context Protocol, including a local server you launch yourself. See docs/MCP_SUPPORT.md and the zero-dependency bridge mcp/llm-bridge.mjs.
